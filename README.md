# AI Workspace Suite

Build a polished, responsive **AI Workplace Productivity Assistant** web application based closely on the attached reference image.

## Goal

Create a premium, modern SaaS productivity dashboard where users can access three AI-powered productivity tools:

1. **Smart Email Generator**
2. **Meeting Notes Summarizer**
3. **AI Task Planner**

The application should feel like a real, polished productivity product rather than a basic prototype.

Use the attached screenshot as the **primary visual reference**. Recreate its overall visual language, layout, spacing, hierarchy, navigation, card styling, responsive behavior, and mobile experience while keeping the final design original.

The application should be fully interactive and usable as an MVP.

All AI functionality can use realistic demo/mock responses. No real AI API is required.

# MOBILE EXPERIENCE

The mobile experience is extremely important.

The application should feel intentionally designed for mobile rather than simply shrinking the desktop version.

On mobile:

* Hide the desktop navigation.
* Show a compact top header.
* Include hamburger menu.
* Display AI Workplace branding.
* Include notification access.
* Open navigation inside a mobile drawer when the hamburger is selected.

Dashboard feature cards should stack vertically.

Recent Activity should remain easy to scan.

Forms should be comfortable to use on small screens.

Buttons should be easy to tap.

Create a fixed bottom navigation with:

* Dashboard
* Email
* Notes
* Tasks
* History

Each item should include an icon and label.

Pay particular attention to layouts around:

* 320px
* 375px
* 390px
* 768px
* 1024px
* 1440px+

Nothing should feel cramped, overflow horizontally, or become difficult to use.

# DEMO AI BEHAVIOR

This is an MVP, so AI responses can be simulated.

However, the demo responses should feel believable and contextual.

For example:

If a user asks for a project update email with a friendly tone, generate a friendly project update rather than generic placeholder text.

If meeting notes mention decisions, deadlines, or specific people, the summary should reflect those details.

If users enter several tasks, the generated plan should organize those tasks into a sensible schedule.

The user should feel like they are interacting with an AI assistant even though no external AI service is connected.

---

# PERSISTENCE

Important user actions should persist between sessions.

Persist:

* Generated emails
* Meeting summaries
* Task plans
* History
* Completed tasks
* Templates/preferences where appropriate
* Settings

Refreshing the application should not erase saved demo data.
